# Saved maps (local)

3D point clouds from FAST-LIO (`map_save` or exit with `pcd_save_en: true`).

Default save path in config: `/tmp/fast_lio_map.pcd`

```bash
mkdir -p maps
cp /tmp/fast_lio_map.pcd maps/my_map.pcd
```

`*.pcd` files are gitignored (too large for the repo). Keep copies here on your machine.
